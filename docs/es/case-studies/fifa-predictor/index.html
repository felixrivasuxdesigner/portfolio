Resumen del Proyecto

Quiniela Engine es una plataforma privada y automatizada para jugar quinielas deportivas entre amigos. Nació para el Mundial FIFA 2026 y evolucionó a un motor que se adapta a distintos torneos: la edición actual se prepara para el Mundial de Rugby 2027, con sus pools, puntos bonus y fase eliminatoria. Combina un frontend web rápido, resultados reales sincronizados automáticamente y un bot de IA diario en WhatsApp.

El Desafío

Las quinielas de torneos deportivos suelen gestionarse en planillas de Excel manuales, lo que causa retrasos en las actualizaciones, errores de cálculo y disputas entre participantes. Además, carecen de interactividad móvil inmediata. El reto era automatizar el 100% del ciclo de vida del juego (carga de pronósticos, cálculo de puntajes reales) e integrar una capa social humorística e interactiva que mantuviera el engagement diario de los usuarios sin mantenimiento manual.

Propuesta de Valor

Desarrollamos un ecosistema automatizado e inmersivo con las siguientes ventajas:

  • Motor multitorneo: la misma base soporta fútbol y rugby, cada uno con su identidad visual y sus reglas (grupos o pools, puntos bonus, fases eliminatorias y desempate pre-torneo).
  • Frontend React 19 & Tailwind CSS v4: interfaz rápida, optimizada para cargar pronósticos desde el celular.
  • Sincronización automática: scripts en Node.js consultan APIs de resultados y recalculan marcadores y puntajes en Supabase.
  • DT de Sofá (bot de IA en WhatsApp): integrado con Evolution API y Groq, analiza la tabla cada noche y responde con burlas al grupo y por mensaje directo.
  • Seguridad e integridad: reglas en Supabase (RLS) bloquean cambios en los pronósticos una vez iniciado cada partido.

Proceso de Desarrollo y UX

Modelado de Dinámica y Reglas

Definición del sistema de puntaje (exacto, ganador, empate, fase) y el umbral de bloqueo de predicciones (75 minutos antes del partido) para evitar conductas ventajosas.

Diseño de Interfaz Inmersiva

Creación de una UI oscura estilo 'estadio deportivo' con acentos verdes neón y morados, utilizando tipografía moderna y cards limpias para optimizar la lectura rápida de marcadores.

Sincronizador Automático de Datos

Configuración de scripts cron en macOS y launchd para consultar periódicamente la API de fútbol, actualizar la base de datos Supabase y gatillar las actualizaciones de puntajes de los usuarios.

Capa Social con IA (DT de Sofá)

Diseño y estructuración del prompt de IA de 'El DT de Sofá'. El bot lee la tabla de posiciones en Supabase y redacta un roast sarcástico en WhatsApp humillando amigablemente al colista y elogiando al líder.
