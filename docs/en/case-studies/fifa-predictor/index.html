Project Overview

A private, hyper-competitive, and fully automated prediction platform designed to manage the FIFA World Cup 2026 sweepstakes among a closed group of friends. The project combines a modern, fast web frontend with real-time official match score synchronization and a daily AI WhatsApp bot that adds a dynamic, hilarious element to the game.

The Challenge

Sports sweepstakes are traditionally managed via manual Excel spreadsheets, leading to update delays, calculation errors, and disputes among participants. They also lack immediate mobile interactivity. The challenge was to automate 100% of the game lifecycle (prediction submissions, official score sync, and ranking updates) and integrate a humorous, interactive social layer to maintain daily engagement without manual intervention.

Value Proposition

We developed an automated and immersive ecosystem with the following advantages:

  • React 19 & Tailwind CSS v4 Frontend: An ultra-fast, dark-mode web application optimized for smooth prediction submissions on mobile devices.
  • Automated Synchronization: Node.js scripts that poll official FIFA matches and update Supabase standings in real-time.
  • Sofa Coach (AI WhatsApp Bot): Bot integrated via Evolution API and Groq (Llama 3.1) that analyzes the standings daily to post sarcastic and comical updates in the group chat.
  • Security & Integrity: Strict Row-Level Security in Supabase to lock predictions once a match has started.

UX & Development Process

Rules & Database Modeling

Defined the scoring rules (exact score, winner/draw, tournament phases) and the automated prediction lock threshold (75 minutes before kickoff) to maintain fair play.

Immersive UI/UX Design

Created a sports-arena dark mode interface using neon green and purple accents, clean typography, and spacious card layouts for quick scoreboard scanning.

Automated Sync Workflows

Configured cron scripts on macOS using launchd to regularly check the football API, update Supabase records, and recalculate user rankings.

Sofa Coach Prompt Engineering

Designed and tested the AI agent prompts for the 'Sofa Coach'. The bot reviews the database standings and drafts a hilarious daily roast message in the WhatsApp group.
