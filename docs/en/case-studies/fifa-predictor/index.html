Project Overview

Quiniela Engine is a private, automated platform for sports prediction pools among friends. It was born for the 2026 FIFA World Cup and evolved into an engine that adapts to different tournaments: the current edition is being prepared for the 2027 Rugby World Cup, with its pools, bonus points and knockout stage. It combines a fast web frontend, real results synced automatically and a daily AI bot on WhatsApp.

The Challenge

Sports sweepstakes are traditionally managed via manual Excel spreadsheets, leading to update delays, calculation errors, and disputes among participants. They also lack immediate mobile interactivity. The challenge was to automate 100% of the game lifecycle (prediction submissions, official score sync, and ranking updates) and integrate a humorous, interactive social layer to maintain daily engagement without manual intervention.

Value Proposition

We developed an automated and immersive ecosystem with the following advantages:

  • Multi-tournament engine: the same codebase supports football and rugby, each with its own visual identity and rules (groups or pools, bonus points, knockout stages and a pre-tournament tiebreaker).
  • React 19 & Tailwind CSS v4 frontend: a fast interface optimized for entering predictions on a phone.
  • Automatic sync: Node.js scripts query results APIs and recalculate scores and points in Supabase.
  • Couch Coach (AI bot on WhatsApp): built with Evolution API and Groq, it analyzes the standings every night and roasts players in the group chat and by direct message.
  • Security and integrity: Supabase rules (RLS) lock predictions once each match kicks off.

UX & Development Process

Rules & database modeling

Defined the scoring system (exact score, winner, draw and stage) and database-level locks: each prediction closes at its match's kickoff, and the pre-tournament podium closes with the tournament's first match.

Identity per tournament

The 2026 FIFA edition started with a dark theme and moved to a light one with the World Cup palette. For rugby, components were reskinned by mapping the theme tokens to the RWC palette, without rewriting classes. Anton for scores and Noto Sans for the interface carry over to both.

Automated Sync Workflows

Configured cron scripts on macOS using launchd to regularly check the football API, update Supabase records, and recalculate user rankings.

Sofa Coach Prompt Engineering

Designed and tested the AI agent prompts for the 'Sofa Coach'. The bot reviews the database standings and drafts a hilarious daily roast message in the WhatsApp group.
