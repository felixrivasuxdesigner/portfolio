Project Overview

AgileRadar is an internal intelligent bidding scouting and proposal drafting platform built for Shape. The system interfaces with Chile's public procurement portal (Mercado Público) to evaluate incoming bids and draft commercial proposals in minutes.

The Challenge

Scouting public bids on government portals is a tedious process requiring managers to read through extensive PDF or Word documentation (typically 50-100 pages per bid). Evaluating technical fit is manual and consumes days, meaning high-value opportunities can easily be missed. The challenge was to centralize, automatically assess fit using AI, and generate technical-commercial proposal drafts.

Value Proposition

We designed an automated pre-qualification workflow combining natural language processing and real-time visualization:

  • Real-Time Kanban Board: Opportunities organized across pipeline stages, utilizing WebSockets for instant interface updates.
  • AI fit-scoring: each tender is evaluated against Shape's capabilities with a 0 to 100 score and a written justification. Groq (GPT-OSS models) is the primary provider, with Gemini and a local model (Ollama) as fallbacks.
  • Multi-Document consolidator: Drag-and-drop document upload (PDF/Word) that extracts text and compiles it into a structured reference context.
  • Technical Proposal Draft Engine: Instant generation of tailored proposals addressing critical Chilean bidding criteria in Markdown format.

UX & Design Process

Mapping Shape's Core Stack

Interfaced with Shape's team to define core criteria (UI/UX, React/TS, Design Systems) and structured them as system constraints for the AI scoring model.

Kanban Pipeline Design

Structured the board to display bids based on their compatibility match_score, automatically filtering out low-scoring bids to reduce manager cognitive fatigue.

Consolidating Bidding Documents

Created an intuitive sidebar drawer supporting multiple drag-and-drop document uploads, parsing them on-the-fly to construct the context package.

Interactive Proposal UX

Designed an interface that allows managers to read, refine, and edit proposal AI-generated drafts before downloading them as Markdown or Word.
