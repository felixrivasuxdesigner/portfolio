Project Overview

Grant Thornton Chile required a unified and modernized ecosystem for its internal tax compliance tools, consolidated into a single secure portal named BusinessTools. As Lead UX/UI Designer, the challenge was to design a robust corporate design system in React, TypeScript, and CSS Modules, fully documented in Storybook, serving as a consistent foundation across three independent repositories (tax-portal-frontend, portalgt-backend, and celery-k8s).

The Challenge

The platform processes heavy financial data density: complex tax grids (annual F22, monthly F29, additional F50), real-time scraping bot monitors, and company group assignments. The primary UX hurdle was to present dense tax details cleanly and accessibly following Apple's HIG (Human Interface Guidelines). Furthermore, the portal required a strict role-based access control system (RBAC) and alternative flat styling configurations for exporting reports to PDF (via WeasyPrint) and emails (Mailing) without modern CSS support.

Grant Thornton BusinessTools Design System

A professional, accessible, and adaptive component system based on native Apple HIG aesthetics, combining official Grant Thornton brand colors with optimized guidelines for web applications and PDF/Mailing exports.

Value Proposition

We engineered an interactive, atomic component library tailored for corporate compliance and legibility:

  • Atomic Design Architecture: Structured components strictly into Atoms, Molecules, Organisms, and interactive demo Pages in Storybook.
  • Adaptive Apple HIG Aesthetic: Floating cards on grouped backdrops (#F2F2F7), clean 16px corner radii, subtle shadows, and backdrop blur effects (glassmorphism).
  • Specialized UI Export Modes: Dedicated Storybook configuration that discards border radii, drop shadows, and scale transforms to guarantee clean render outputs in PDFs and enterprise email clients.
  • Embedded Access Control (RBAC): Built-in control components like 'PermissionGuard' and reactive authorization hooks to dynamically hide/show menu items and operations based on user privileges.

UX & Development Process

Mapping Financial Workflows

Interfaced with accountants and tax analysts to organize annual income, monthly sales tax, and supplementary tax filings into a logical information hierarchy.

Storybook Component Library

Developed and tested components (buttons, grids, inputs, OCR upload areas) with live controls in Storybook to guarantee consistent behavior and WCAG 2.1 AA accessibility.

Optimizing for Limited CSS Engines

Investigated and developed flat UI variations specifically adapted for the Python WeasyPrint engine and enterprise Outlook email rendering.

Role-Based Navigation and Skeletons

Designed dynamic menu states based on user roles and custom skeletons to reduce perceived wait times during complex report generation.
